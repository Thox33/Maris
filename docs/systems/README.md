# System Docs

This section is for focused documentation of concrete gameplay or UI systems.

Use this category when a document explains how one concrete system is structured internally.

System docs may describe either:

- the currently implemented internal behavior of a system
- the fixed target structure of a concrete system that the codebase is actively moving toward

What does not belong here:

- broad project-wide architecture models
- generic planning documents with phased rollout steps
